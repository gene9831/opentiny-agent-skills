# TinyVue 组件库开发助手

该技能包提供了`TinyVue组件库` 的菜单，使用文档，组件API,和 组件demo 等知识，方便用户**快速生成准确的代码**, 请根据下面的指令获取信息。

## 文件夹说明

- ./menus.js : 存放所有开发文档的链接信息以及组件的目录。
- ./webdocs: 存放所有开发文档的详细内容。
- ./apis : 存放每一个组件的api文档，包含：属性，事件，插槽和一些类型信息
- ./demos: 存放每一个组件的示例

### menus.js 格式说明

在 `docMenusChildren` 的变量中，存放着开发文档说明，其中每一项数据的 `title` 记录着文档的标题， `key` 记录着文档的文件名，具体文件在 ./webdocs 目录中。 比如：

```javascript
{ 'title': '国际化', 'titleEn': 'i18n', 'key': 'i18n' }
```

表示组件库的国际化文档存放在 `./webdocs/i18n.md` 中。

在 `cmpMenus` 变量中，存放的组件的目录，它包含着二级数据，第一层是组件的类型，第二层数据才是真正的组件信息，第二层的每一项数据的`name` 记录着组件的名称， `namecN` 记录着组件的中文名称， `key` 记录着组件的小写连字符格式的组件名。通过 `key` 属性可以在`apis`中找到相应的组件API文档， 在`demos`中找到相应的组件示例的文件夹。

### webdocs 文件夹说明

这里存放着标准的 md 文档，以 `*-en.md` 结尾的文件是英文文档，其它则是中文文档，引用时，必须使用中文文档。

### apis 文件夹说明

在该目录中，每一个文件对应一个组件的API, 其文件名对应于组件英文名，比如： `action-menu.js` 就是对应着 `ActionMenu` 组件。

每一个API文件中，`apis`属性是一个数组，以描述复杂组件可能包含多个组件，比如 Form 和 FormItem， 这时每一个数组项就对应着一个组件的 API 信息。`types`属性也是一个数组，描述着当前组件用到的一些`typescript`类型的描述。

一个组件的API信息包含：name, props,events,methods,slots等信息。

在组件的API信息的`props`描述了组件有哪些属性，`events`描述了组件有哪些事件，`methods`描述了组件补全有哪些方法 ，`slots`描述了组件有哪些插槽。

在这些描述信息中，`name`是相应的属性值，`type`是相应的属性类型， `desc`属性中包含中英文的描述，引用时必须引用中文的描述。`pcDemo`属性指向了这个属性关联着的demos示例文件，指向 `./demos/{组件名}/{pcDemo指向名称}.vue` 这个具体的demo源码。`typeAnchorName`属性，指向了它类型的详细接口定义，通常放在`types`数组中。

### demos 文件夹说明

在该目录中，每一个文件夹对应一个组件的全部示例，其中文件名规则是：

- `${组件名}/webdocs/${组件名}.js` 文件的`demos`属性存放着该组件所有的示例目录，记录着示例的说明和示例指向的示例源码
- `${组件名}/${示例名}.vue` Vue的选项式语法的示例源码
- `${组件名}/${示例名}-compossition-api.vue` Vue的组合式语法的示例源码

## 指令

### 严格查找流程，严禁跳过任意阶段

1. **组件名查找阶段** ：从`menu.js`中找到适合的组件名称
2. **查找API信息阶段**: 通过组件名称，在`apis`中查找组件的api 文档
3. **示例查找阶段**： 通过组件名称，在`demos`中查找组件的示例源码，首先要查看`basic-usage.vue`的基础用法，再查看其它的示例用法。查找到准确的示例后，就不要再查找其它示例。

### 查找约束规则

1. 要根据组件名进行关联查询API和示例，严禁使用其它开源库的属性，来猜测TinyVue组件库的用法。
2. 读取属性描述或示例描述时，必须使用它的中文描述信息，通常是在 `zh-CN`中描述的。
3. 查找不到相应的属性或示例时，不得自行推断或替换其它信息。
4. 遇到错误时，不得自行推断或替换其它信息。
