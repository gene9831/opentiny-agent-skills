# 录制组件演示 GIF

1. **挑选故事。** 从用户指定的功能和当前实现或差异中挑出观众需要亲眼看到的交互。用一句话写出每段的「起始状态 → 操作 → 可见结果」。把鼠标和键盘等不同使用路径拆成独立 GIF，除非它们自然属于同一段操作。只录能说明功能的步骤。
2. **准备独立场景。** 优先复用现有组件预览。需要时在项目的临时目录加一个场景入口，每个 URL 固定数据、组件配置、容器宽度、初始滚动和焦点。用真实组件与真实输入；准备数据、切模式等调试操作应在录制前完成。让组件占据主要画面，去掉示例外层的大边框、常驻标题、说明和调试控件。演示窄容器时区分容器宽度和浏览器视口。
3. **排好节奏。** 长片段在第一次操作前短暂显示一句开场文字，说明本次改动或可见效果，进入演示后撤下开场。对触发方式或结果不明显的动作，加简短字幕并在画面底部预留空间。按能力组织的演示可选用[能力标签 + 示例说明](references/webreel.md#能力标签与示例说明)，左侧突出能力，右侧说明画面里的效果。键盘场景先显示焦点从哪里开始，再真实发出按键，让键帽提示与焦点移动同时可见。比如长目录可依次展示 Tab 进入、End 跳到末项、↑/↓ 移动、Home 回到首项，具体按键以组件实际支持为准。
4. **录制和合成。** 先确认本地预览可用并达到正确初始状态，再用可重复的操作脚本录制。用稳定选择器定位动作，滚动时明确目标容器，等待悬停延迟或滚动动画完成，并留时间看清操作结果。使用 Webreel 时读取 [录制与字幕](references/webreel.md)，其中有命令、配置要点和可复用的字幕合成脚本。
5. **验收成片。** 播放最终 GIF 或提取关键帧检查开场、首个动作、焦点或滚动变化、最终状态和循环衔接。确认字幕与实录同步、文字和按键可辨认、组件没有被裁切或遮挡。检查尺寸、时长和文件大小。交付本地 GIF 和对应路径。MP4、时间线和字幕配置是中间文件，交付范围到本地成片为止。
